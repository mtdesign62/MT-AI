# Model Licenses

## Qwen/Qwen-Image-2.1

The model card currently identifies the license as `qwen-research`. Review the complete current upstream license before commercial distribution of MT AI or any hosted/commercial service using these weights.

## Qwen/Qwen-Image-2.1-PE-I2I

The model card currently identifies the license as `qwen-research`. Treat it separately from MT AI application source licensing.

## Future models

No model may be added to the default registry without documenting:

- upstream repository;
- exact revision;
- license;
- commercial restrictions;
- approximate disk/VRAM requirements;
- compatibility result.

MT AI application source currently contains no selected open-source application license; the repository owner should choose one before public redistribution.
